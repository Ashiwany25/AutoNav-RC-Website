Features

📱 Android control

Standalone Flutter app that connects to a local controller over HTTPS.

🗺️ Saved indoor map

Choose reachable destinations on a saved occupancy-grid map.

🧭 A* route planning

Plan safe virtual routes while preserving obstacle clearance.

🛑 Safety controls

STOP command, heartbeat monitoring and connection-loss handling.

🔐 Local pairing

Pair with a local backend using a temporary code and bearer authentication.

🔁 Dynamic replanning

Simulation support for changed destinations and detected obstacles.

Installation

  1. Download the APK on an Android phone.
  2. Allow installation from the selected source if Android requests it.
  3. Install and open AutoNav RC.
  4. Run the companion FastAPI backend on a trusted local network.
  5. Pair the phone and activate the controller through the app's settings.
  6. Open Saved Map Navigation, choose a safe cell and start simulation.
Important: Development version

This build uses a development-specific controller address and trusted certificate. Installing the APK alone will not provide an operational controller. The car movements are currently simulated: no physical motors are controlled. Do not use this build to control an unattended physical vehicle. Public multi-device onboarding is not yet supported.

Release integrity

The SHA-256 checksum is included in SHA256SUMS.txt. Compare it with the downloaded APK to verify file integrity.
