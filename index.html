Download the Android development APK

Download AutoNav-RC.apk

APK install alone does not start a robot or backend. This development build is pinned to a specific controller IP and certificate.

  1. Install the APK on an Android phone after reviewing Android's install prompt.
  2. Run the matching AutoNav RC FastAPI HTTPS server on a trusted local network.
  3. Connect phone and server to the same Wi-Fi, pair with a local code, and activate the controller.
  4. Open Saved Map Navigation to test simulated navigation and STOP behavior.

SHA-256 verification: SHA256SUMS.txt

⚠️ Development-only project

The public APK is configured for the original development controller and will not automatically connect to other users' hardware. The demonstration does not control a physical RC car. Real sensors, mapping/localization, motor control, emergency-stop hardware, and secure per-device onboarding remain future work. Never use this version as a safety-critical vehicle controller.
